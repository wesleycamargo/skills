# Wesley Humanizer Skill

This skill rewrites and reviews text so it sounds like Wesley Camargo: practical, direct, technical, and human.

## Files

- `SKILL.md`: the skill definition
- `synthetic-persona-writing-style.md`: the local writing style reference

## How to use

Copy this folder into your skills repository or install it with your preferred skill manager.

Example prompt:

```text
Use the wesley-humanizer skill and rewrite this README section in my style.
```

## Best use cases

- README files
- LinkedIn posts
- technical tutorials
- architecture notes
- Azure and DevOps documentation
- internal updates
- runbooks

## Notes

The skill is inspired by the Humanizer skill pattern, but it is adapted to Wesley's writing style and technical audience.
